# FL-089 · Landing bilingüe y páginas legales

> Caso de QA escrito antes de construir (WP-45). WP-42 lo actualiza con lo que cambie al construir. Fuente: `docs/flows-catalog.md` FL-089.

| Campo | Valor |
|---|---|
| Área | J · Consola y superficies públicas |
| Actores · canal | Público · web (`/`, `/legal/privacy.html`, `/legal/terms.html`) |
| Reglas | Neutralidad de marca (ADR-0006); cabeceras de seguridad |
| Depende del modelo | No |
| Pruebas | U `views/landing/landing.test.ts` · UI `landing.spec.ts` · SMK `SMK/1` |

## Entrada

- La landing construida (`npm run build -w packages/web`) y las páginas legales.
- La lista externa de términos prohibidos (`FORBIDDEN_TERMS`) para `lint:forbidden -- --dist`.

## Pasos

1. Abrir `/`; cambiar es/en; recorrer la galería con zoom (anterior/siguiente, teclado, swipe, Escape); tocar "Judges: sign in / Jurado: ingresar".
2. Abrir las dos páginas legales.
3. `SMK/1`: `curl` de `/` y de las legales con cabeceras (reintento de 30 s).

## Resultado esperado

1. HTTP 200 en las tres rutas con CSP, HSTS, `X-Frame-Options DENY` y `nosniff`.
2. (landing) "Legajo listo · Powered by Craftech"; aviso de datos 100 % sintéticos; bloque "Qué es real y qué es simulado" (WhatsApp como adaptador implementado en modo simulado, nunca como canal vivo); conmutador es/en; galería con zoom accesible por teclado.
3. El botón para jurados lleva a `/login`.
4. `npm run lint:forbidden -- --dist` en verde: ningún nombre de cliente ni término prohibido en el build.

## Cobertura por nivel

| Nivel | Prueba | Qué asierta con la etiqueta `[FL-089]` |
|---|---|---|
| U | `views/landing/landing.test.ts` | Textos es/en con las mismas claves, bloque real/simulado presente, "Powered by Craftech", ningún texto de WhatsApp como canal vivo |
| UI | `landing.spec.ts` | Conmutador, galería (teclado, swipe, Escape), botón a `/login`, accesibilidad básica |
| SMK | `SMK/1` | Landing y legales 200 con cabeceras |
