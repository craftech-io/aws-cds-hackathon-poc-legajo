## Entrada

- SR: clon de `op-4471` en `SC-19`; `reader.setFaults(ERROR_503)` y después `TIMEOUT` para el reloj del mundo (`FAULTS#<clockId>`).
- Un PDF que llega (por `supplier.sendNow` o por WhatsApp).

## Pasos

1. Intake con el lector fallando: 3 reintentos → `READER_UNAVAILABLE` → versión `RECEIVED` y `TIMER#READER_RETRY` a + 30 min.
2. Avanzar dos `READER_RETRY` con el lector todavía fallando → tercer fallo → `Escalation READER_UNAVAILABLE`.
3. `reader.setFaults(NONE)` → avanzar al reintento → la lectura completa el flujo.
4. `op.settle` después de cada paso.

## Resultado esperado

1. (snapshot) Versión `RECEIVED` sin lectura mientras el lector falla; ninguna lectura inventada ni documento `VALID` sin lectura.
2. (snapshot) `TIMER#READER_RETRY` cada 30 min simulados; al tercer fallo, un escalamiento `READER_UNAVAILABLE`.
3. (snapshot) Con el lector de vuelta: lectura guardada, documento con el estado que corresponde y el flujo sigue (turno `DOCUMENT_READ`).
4. Ningún otro mundo afectado: la falla solo aplica con `X-Fault-Scope` del reloj `qa-*`.
